# 🔮 Dukun Online

Dukun Online adalah aplikasi web yang menyediakan simulasi konsultasi dukun secara online dengan tampilan modern dan interaktif. Pengguna dapat melakukan konsultasi virtual, melihat layanan yang tersedia, serta mendapatkan pengalaman hiburan berbasis web yang unik dan menarik.

## 🌐 Demo

Aplikasi dapat diakses melalui:

https://dukun-online-production.up.railway.app/home

## ✨ Fitur Utama

- Halaman beranda interaktif
- Informasi layanan perdukunan virtual
- Sistem konsultasi online
- Tampilan responsif untuk desktop dan mobile
- Antarmuka sederhana dan mudah digunakan
- Desain modern berbasis web

## 🚀 Cara Menjalankan Proyek

### 1. Clone Repository

```bash
git clone https://github.com/wafiqnuraliyah445/dukun-online.git
```

### 2. Masuk ke Folder Proyek

```bash
cd dukun-online
```

### 3. Install Dependency

```bash
composer install
```

### 4. Konfigurasi Environment

Salin file `.env.example` menjadi `.env`

```bash
cp env .env
```

Atur konfigurasi database pada file `.env`.

### 5. Jalankan Server

```bash
php spark serve
```

Aplikasi akan berjalan di:

```bash
http://localhost:8080
```
